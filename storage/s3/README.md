# S3-Compatible Storage Driver

S3-compatible storage driver for Glib Storage using MinIO SDK. Supports AWS S3, MinIO, DigitalOcean Spaces, Backblaze B2, and other S3-compatible services.

## Installation

```bash
go get github.com/azizndao/glib/storage/s3
```

## Features

- ✅ Full S3 API support via MinIO SDK
- ✅ Works with AWS S3, MinIO, DigitalOcean Spaces, Backblaze B2, etc.
- ✅ Presigned URLs for temporary access
- ✅ Streaming support for large files
- ✅ Custom metadata support
- ✅ Multipart upload support (handled by MinIO SDK)

## Supported Providers

| AWS S3              | ✅     | Full support                       |

| DigitalOcean Spaces | ✅     | S3-compatible                      |

## Usage

### AWS S3

```go
import "github.com/azizndao/glib/storage/s3"

disk, err := s3.New(s3.Options{
    Endpoint:  "s3.us-east-1.amazonaws.com",
    AccessKey: "AKIAIOSFODNN7EXAMPLE",
    SecretKey: "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
    Bucket:    "my-bucket",
    Region:    "us-east-1",
    UseSSL:    true,
})
```

### MinIO (Self-Hosted)

```go
disk, err := s3.New(s3.Options{
    Endpoint:  "minio.example.com:9000",  // Or "localhost:9000" for local
    AccessKey: "minioadmin",
    SecretKey: "minioadmin",
    Bucket:    "uploads",
    UseSSL:    false,  // or true if using HTTPS
})
```

### DigitalOcean Spaces

```go
disk, err := s3.New(s3.Options{
    Endpoint:  "nyc3.digitaloceanspaces.com",
    AccessKey: "YOUR_SPACES_KEY",
    SecretKey: "YOUR_SPACES_SECRET",
    Bucket:    "my-space",
    Region:    "nyc3",
    UseSSL:    true,
})
```

### Backblaze B2

```go
disk, err := s3.New(s3.Options{
    Endpoint:  "s3.us-west-001.backblazeb2.com",
    AccessKey: "YOUR_KEY_ID",
    SecretKey: "YOUR_APPLICATION_KEY",
    Bucket:    "my-bucket",
    Region:    "us-west-001",
    UseSSL:    true,
})
```

## Configuration Options

| Option              | Type         | Required | Default             | Description                                                        |
| ------------------- | ------------ | -------- | ------------------- | ------------------------------------------------------------------ |
| `Endpoint`          | `string`     | Yes      | -                   | S3 endpoint (e.g., `s3.amazonaws.com` or `minio.example.com:9000`) |
| `AccessKey`         | `string`     | Yes      | -                   | Access key ID                                                      |
| `SecretKey`         | `string`     | Yes      | -                   | Secret access key                                                  |
| `Bucket`            | `string`     | Yes      | -                   | Bucket name                                                        |
| `Region`            | `string`     | No       | `""`                | Bucket region (required for AWS S3)                                |
| `UseSSL`            | `bool`       | No       | `false`             | Use HTTPS for connections                                          |
| `BaseURL`           | `string`     | No       | `""`                | Custom base URL for file access (useful for CDN)                   |
| `DefaultVisibility` | `Visibility` | No       | `VisibilityPrivate` | Default visibility for new files                                   |
| `Prefix`            | `string`     | No       | `""`                | Path prefix for all operations                                     |

## Presigned URLs

Generate temporary URLs for secure file access without proxying through your application:

```go
// Generate presigned URL (expires in 1 hour)
url, err := disk.TemporaryURL(ctx, "private/document.pdf", time.Now().Add(1*time.Hour))
// Returns: https://bucket.s3.amazonaws.com/private/document.pdf?X-Amz-Algorithm=AWS4-HMAC-SHA256&...
```

These URLs are generated by the S3 service and are automatically validated by S3 - no custom middleware needed!

## Custom Metadata

S3 supports custom metadata on objects:

```go
file := storage.NewFile("document.pdf", size, reader)
file.WithMetadata("user_id", "123")
file.WithMetadata("department", "engineering")

disk.PutFile(ctx, "documents/doc.pdf", file)
```

## Path Prefixes

Use prefixes to organize files or implement multi-tenancy:

```go
// Tenant-specific storage
disk, err := s3.New(s3.Options{
    Bucket: "shared-bucket",
    Prefix: "tenant-abc",  // All operations scoped to tenant-abc/*
    // ... other options
})

// File is stored at: tenant-abc/uploads/file.txt
disk.Put(ctx, "uploads/file.txt", reader)
```

## Performance Tips

1. **Use Streaming** - The MinIO SDK automatically handles streaming
2. **Multipart Uploads** - Large files are automatically split into parts
3. **Connection Pooling** - MinIO client maintains connection pool
4. **Regional Endpoints** - Use region-specific endpoints for AWS S3 to reduce latency

## Limitations

- **Visibility Control**: MinIO SDK has limited ACL support. `SetVisibility()` returns `ErrNotImplemented`
- **Directories**: S3 doesn't have true directories; they're simulated with key prefixes
- **Metadata in Listing**: File metadata not included in list operations (fetch individually)

## Example: Complete Setup

```go
package main

import (
    "context"
    "log"
    "strings"
    "time"

    "github.com/azizndao/glib/storage"
    "github.com/azizndao/glib/storage/s3"
)

func main() {
    ctx := context.Background()

    // Create S3 disk (MinIO example)
    disk, err := s3.New(s3.Options{
        Endpoint:  "localhost:9000",
        AccessKey: "minioadmin",
        SecretKey: "minioadmin",
        Bucket:    "uploads",
        UseSSL:    false,
    })
    if err != nil {
        log.Fatal(err)
    }

    // Upload a file
    content := strings.NewReader("Hello from S3!")
    err = disk.Put(ctx, "greetings/hello.txt", content)
    if err != nil {
        log.Fatal(err)
    }

    // Generate presigned URL (valid for 1 hour)
    url, err := disk.TemporaryURL(ctx, "greetings/hello.txt", time.Now().Add(1*time.Hour))
    if err != nil {
        log.Fatal(err)
    }
    log.Println("Presigned URL:", url)

    // List all files in bucket
    files, err := disk.AllFiles(ctx, "")
    if err != nil {
        log.Fatal(err)
    }
    log.Println("Files:", files)

    // Stream large file
    stream, err := disk.GetStream(ctx, "greetings/hello.txt")
    if err != nil {
        log.Fatal(err)
    }
    defer stream.Close()

    // Process stream...
}
```

## Running MinIO Locally

For development/testing:

```bash
# Using Docker
docker run -p 9000:9000 -p 9001:9001 \
  -e "MINIO_ROOT_USER=minioadmin" \

# Access S3 API at http://localhost:9000
```

## Testing

```go
func TestS3Storage(t *testing.T) {
    // Requires MinIO or S3 credentials
    if testing.Short() {
        t.Skip("Skipping S3 integration test")
    }

    disk, err := s3.New(s3.Options{
        Endpoint:  "localhost:9000",
        AccessKey: "minioadmin",
        SecretKey: "minioadmin",
        Bucket:    "test-bucket",
        UseSSL:    false,
    })
    require.NoError(t, err)

    ctx := context.Background()

    // Test file operations
    err = disk.Put(ctx, "test.txt", strings.NewReader("content"))
    assert.NoError(t, err)

    data, err := disk.Get(ctx, "test.txt")
    assert.NoError(t, err)
    assert.Equal(t, []byte("content"), data)
}
```

Run tests:

```bash
# Skip S3 tests
go test -short ./...

# Run all tests (requires MinIO/S3)
go test ./...
```

## Troubleshooting

### Connection Refused

```
Error: dial tcp: connect: connection refused
```

**Solution**: Ensure MinIO/S3 endpoint is accessible and UseSSL matches server configuration.

### Access Denied

```
Error: Access Denied
```

**Solution**: Verify access key, secret key, and bucket permissions.

### Invalid Endpoint

```
Error: lookup minio: no such host
```

**Solution**: Check endpoint format. Use IP or FQDN without protocol prefix.
